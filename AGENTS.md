# For coding agents and reviewers

Read `CLAUDE.md` first. It is binding: what the game is, how we work, where every piece comes from.

## Code Review Rules

Review every pull request against `CLAUDE.md` and against the "done" lines of the current milestone in `docs/milestones/`. Say so when a change loosens a test, adds a dependency, breaks an iPhone platform rule, or builds something the current milestone doesn't ask for.
